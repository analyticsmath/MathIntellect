## C. Exact handoff sheet

### Transition T01 — hero photograph → evidence plate
**Trigger:** scroll 0.07–0.35 within entry scene.  
**Source:** actual hero photo DOM actor with visual focal object.  
**Movement:** image frame shrinks and migrates into a deliberate offset composition; internal image moves slower than frame (overscan), title changes visual ownership; support crop appears from *same source image* at ~0.12 progress.  
**Handoff:** evidence plate stays physically present while sigma control enters on opposite side.  
**Reverse:** identical crop interpolation in reverse, no second image re-fetch or flash.  
**Do not:** drop opacity of everything then reveal another card.

### Transition T02 — evidence plate → path field
**Trigger:** entry ~0.76 through second scene ~0.28.  
**Continuing object:** trace anchor, exact sigma and seed.  
**Movement:** source frame recedes toward a narrow photographed strip; SVG source point aligns with a measured page-space anchor. The path field grows from that origin.  
**Data:** computed once per parameter state with deterministic helper, never decorative random.  
**Exit:** first path remains while other paths arrive at uneven intervals (not a mechanical 24-item CSS stagger).  
**Do not:** replace imagery with an unrelated technical illustration on a hard section boundary.

### Transition T03 — trajectory spread → readable outcome
**Trigger:** branch scene ~0.61–1.0.  
**Movement:** many paths reduce contrast and apparent ownership, selected trace stabilizes; real sampled variance appears from its related region.  
**Hold:** last ~0.22 normalized progress is deliberately low motion, giving a readable visual summary.  
**Exit:** one parameter label retains contrast and becomes the control handle in T04.  
**Do not:** attach a scrolling wall of equation text under a chart.

### Transition T04 — read → interactive changed assumption
**Trigger:** intervention scene entrance.  
**Movement:** one quiet baseline plane slides 20–50px; comparison plane anticipates without taking over; sigma handle enters with native input hit target ≥44px.  
**Real interactive ownership:** pointer/key events update sigma, seeded simulation is recomputed in React useMemo or equivalent; ScrollTrigger never sets React control state.  
**Route context:** if user navigates to /workbench, only pass these real values, with a sane URL/shared state contract; no pretend scenario persistence if it is not implemented.  
**Do not:** automatically rerun user changes on scroll in a way that overwrites them.

### Transition T05 — baseline → comparison
**Trigger:** change committed by real input OR transition into compare reading state.  
**Movement:** source and changed paths share exact coordinate system; old plot appears as controlled residue. Numerical variance delta is recomputed; one short eased transition conveys change; full values are readable when motion ends.  
**Color:** the changed outcome alone uses state-change accent.  
**State completeness:** slider at any intermediate position produces complete recomputation; do not wait for 300ms hover timer to show results.  
**Do not:** claim every increase in theoretical volatility raises every finite-sample variance.

### Transition T06 — comparison → horizontal cinema
**Trigger:** end of comparison reading state.  
**Movement:** one paired-result visual passes behind new wide photographic frame. A slim trace remains as route-world continuity while the first model's photograph occupies the screen.  
**Media entry:** next image is decoded/preloaded, with a complete DOM fallback visible on failed media.  
**Exit:** horizontal rail is discoverable because the next image's edge is clearly visible.  
**Do not:** present five model cards in the same grid as five diagram captions.

### Transition T07 — horizontal chapter A→B
**Trigger:** vertical progress mapped to horizontal track travel; each panel has measured natural width.  
**READ** outgoing main image and its concept at rest.  
**ANTICIPATE** 5–12% of incoming frame visible at viewport edge.  
**TRAVEL** outer images move horizontal; incoming crop counter-parallaxes about 35–95px according to available overscan.  
**HOLD** stop or substantially decelerate at an engine identification moment.  
**OVERLAP** secondary actual crop can rise over prior 20–40% frame to establish new hierarchy.  
**TAKEOVER** incoming frame becomes dominant and its real model link is clearly focusable.  
**RESOLVE** outgoing loses ownership only when incoming is readable.  
**REVERSE** reconstruct precise prior composition based on scroll progress; never re-queue a timed animation.  
**Mobile** use native vertical progression through full-bleed photographic chapters (accessible alternative), not simulated horizontal mousewheel drag.  
**Do not:** set a fixed '+=6000px' regardless of actual responsive widths.

### Transition T08 — selected model frame → /models
**Before navigation:** intercept only unmodified internal click; capture source element bounding rect and visual asset ID while it exists; prepare destination route.  
**After mount:** wait for actual selected model image and DOM size. Use real source-to-target geometry via FLIP; crop shifts to target's true focal location.  
**Timeout:** if target not ready promptly, perform short default mask fade and restore normal navigation; no blank holding screen.  
**Keyboard/reduced motion:** semantic link remains and no forced wait.  
**Do not:** invent destination rect or preserve pointer capture across route destruction.

### Transition T09 — Home experiment → /workbench
**Continuing data:** sigma, mu, seed, path count, exact public helper; no future backend identity.  
**Visual:** source path moves into same graph coordinate system if both real regions can be measured. If not, quieter semantic wipe into the actual instrument is superior to fake shared actor.  
**Ownership:** Workbench takes state authority, Home GSAP scene cleans up.  
**Do not:** turn action into a simulated loading tunnel.

### Transition T10 — replay → finale
**Trigger:** replay scene to end.  
**Movement:** first image returns with a different crop and less visual tension; trace collapses to one origin; identity lettering enters as a spatial consequence of scale.  
**CTA:** accessible before the finale reaches its final scroll position.  
**Closing:** oversized MATH INTELLECT lettering. Utility links do not interrupt emotional resolution.  
**Do not:** use a generic portrait/forest simply to fill a giant wordmark background.

## D. Model cinema art direction / photo casting board

| Engine | User question | Photo material brief | Motion verb | Reading asset |
|---|---|---|---|---|
| Monte Carlo | What range of outcomes can this assumption produce? | actual variation or repeatable experiment, deeply photographic, not a sterile stock chart | branch | seeded trajectory ensemble |
| Game Theory | How does another actor's choice affect mine? | meaningful two-person decision context with real spatial tension, not a clichéd chess piece | oppose / respond | real payoff matrix |
| Market | What happens when the conditions move? | real physical trade/logistics/market process with strong subject, no fabricated trading UI | accelerate / shock | model-defined process output |
| Conflict | How do repeated interactions influence outcomes? | authentic group dynamic with observable counter-movement | collide / accumulate | repeated decision states |
| Custom | What if the question itself changes? | authentic experimental calibration/measurement and human intervention | reconstruct | user-specified expression/input |

Images are proposed *roles*, not already secured downloads. Each candidate must support wide and portrait crops and sit next to real engine capabilities. Where a photo concept cannot be meaningfully linked, reject it.
